# BorderPass (Angular 16.1)

```bash
npm install
npm start          # http://localhost:4200
```

- `src/app/core/api.config.ts` → `useMock: false` و `baseUrl` را برای اتصال به API واقعی تنظیم کنید (کد OTP آزمایشی: 12345).
- لینک‌های فوتر: `src/app/shared/footer/footer.component.html`
- لوگوی واقعی را جایگزین `src/assets/images/logo.svg` کنید.
